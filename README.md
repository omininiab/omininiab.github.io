# omininiab.github.io

Portfolio and blog wesite of Ominini

## Shared design assets

`assets/css/shared.css` and `assets/js/shared.js` are the canonical shared styles and page behaviors. The Cost of Living Tracker loads them from `https://www.ominini.com/assets/`, so update shared design or footer behavior here rather than maintaining copies in the tracker repository. Deploy this repository before the tracker so the shared asset URLs are available. The tracker keeps its dashboard styles locally.
